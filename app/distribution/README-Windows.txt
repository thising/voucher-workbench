PDF工作台 0.6.0 · Windows x64 客户试用包

适用：Windows 10 / Windows 11 64位，使用CPU，无需独立显卡。

启动与升级
1. 便携版：解压整个ZIP，双击“PDF工作台.exe”，直接打开独立窗口。
   安装版：运行setup.exe，安装到当前用户后使用“PDF工作台”快捷方式。
2. 首次启动需要Microsoft WebView2运行时；已有则直接使用。缺少时可联网按提示安装，离线电脑先安装独立提供的微软x64离线运行时，再打开工作台。运行时约205MiB，只需安装一次，不用每次更新工具都重装。
3. 再次启动会唤回同一工作台，原任务继续；不会另开外部浏览器。
4. 从0.5.x升级前，在旧服务窗口等待任务完成后按Ctrl+C退出。处理记录继续使用 %LOCALAPPDATA%\VoucherWorkbench，保留整个目录，不要删除锁文件或清空历史。

批量合并
1. 选择待处理文件夹，读取实际层级。默认“当前文件夹”递归合成一份；选择其他级别时，每个对应文件夹一份。旁边有目录示例，浅层直属文件另列合并单元。
2. 重命名索引可留空。使用时选择XLS/XLSX、工作表、表头行、文件夹索引列和文件名列。默认匹配值作为完整PDF名称；未匹配、空值或重复索引的名称冲突会提醒并使用文件夹名。可显式选“文件夹名-索引值”及“取首条”兼容规则。
3. 排除规则一行一条，#开头的整行是注释；支持相对路径及 *、?、**。无效规则忽略并提示，默认忽略index.html、indexImg等辅助文件。输出及处理记录子树自动排除。
4. 扫描后看三栏：左栏合并单元和输出名，中栏文件顺序，右栏预览与方向。可按文件名自然顺序、修改时间、前缀或后缀排序；也可拖动、上下移动或置顶，修改后保存。
5. 图片可手动旋转；PDF逐页预览，默认旋转当前页，也可选择整份。原文件不变。人工核对勾选独立于旋转，不会自动替您确认。
6. 可选“自动调整图片方向”：阅读使用须知和免责声明，明确同意后执行。仅识别图片，PDF需逐页手动旋转。默认4线程，允许1–10；更多线程通常占用更多CPU和内存，不保证成倍提速。
7. 自动处理后以颜色及文字提醒人工核对，可能误转或漏转。未核对及识别失败不阻止合并，来源损坏/文件被改动等实际错误需要处理。请检查最终成品内容与方向并承担使用责任。
8. 点击“执行合并”，选择输出目录，默认待处理文件夹同级“文件夹名-PDF”；核对组数、页数、文件名和未核对提示后开始。合并线程默认4、允许1–10，按合并单元并行；同一份PDF内部页序不变。
9. 在“处理记录”查看进度、取消、继续/重试、保存报告或PDF，也可打开输出文件夹。重试保持原计划及线程，不随之后的偏好改变。

文件与记录
· 支持JPG、PNG、BMP、静态WebP、单页TIFF和普通静态PDF；不跟随符号链接/联接/云占位，不支持网络盘。坏文件、加密、表单、签名、脚本、附件等不支持结构会提示。
· 图片应用EXIF后按当前角度生成A4横/纵页，等比居中不裁切；源PDF保留尺寸、原有旋转及内部页序，再叠加人工角度。不加页眉、页脚、封面或分隔页。
· 不覆盖未知或被外部修改的同名PDF；请更换名称或输出目录。工具拥有的旧成品更新前归档到输出目录.history。
· manifest.json保存在上述处理记录目录的outputs子目录，用于来源指纹、页码、角度、复用、恢复和防覆盖；不会新建在交付PDF旁。阅读/交付PDF不需要这些记录，升级/备份/换电脑请保留完整处理记录。
· 新批量识别/合并偏好分别保存，默认均4线程；旧版设置和复核记录保持兼容，旧默认1线程不改写。
· 同一处理记录目录只允许运行一个服务，同一时刻一个任务。关闭窗口时有活动任务或另存操作，会提示继续处理或取消并等待安全保存后退出。

方向识别局限
历史3,270张图片的4并行评估约23分钟，39/3,270（1.19%）是模型未决率，不是准确率。它们不是本版速度或通用资料识别率承诺；实际耗时随电脑、资料和线程变化。通用资料自动方向的覆盖与准确率尚未由历史样本证明，最终请自行核对。

启动遇到问题
· WebView2缺失：安装微软官方运行时；离线使用单独附件。单位策略阻止安装时联系管理员。
· 旧版/无法联系的实例占锁：切回原服务正常退出后重试，勿强删锁文件；新版不会自动结束其他进程或切换记录目录。
· 目录权限/磁盘错误：按中文原因检查记录目录读写权限、磁盘连接和可用空间。
· 窗口加载失败：保留错误提示及startup-errors记录，正常退出后重启并反馈原因，勿发送带 #token= 的链接或业务资料。
· OCR模型/DLL不可用：仍可手动整理与合并。需要识别时从微软官方安装VC++2019或兼容更新版x64运行库，再启动：
https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

试用与许可
这是未签名客户试用包。请核对来源和SHA256；单位策略阻止时联系管理员，不要关闭安全防护。CI通过不能替代客户Windows10真实双击、WebView2安装、单位策略和实际资料验收。
应用无需Rust、Python、Office、Node或Docker；随包附CPU OCR模型及ONNX Runtime，运行不下载模型/预览组件。WebView2为独立微软组件。
