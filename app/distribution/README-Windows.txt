凭证工作台 · Windows x64 测试包

适用：Windows 10 / Windows 11 64 位，使用 CPU，无需独立显卡。

开始使用
1. 将整个 ZIP 解压到一个目录，不能直接在压缩包中运行。
2. 双击“启动凭证工作台.cmd”。请保留服务窗口，浏览器会自动打开。
3. 选择资料文件夹和明细账，默认第一个工作表，也可以指定工作表。
4. 方向识别默认关闭，可以直接生成；也可以自行旋转图片。
5. 如启用标题方向识别，勾选表示同意旁边的免责声明。识别完成后，人工检查、按需修正并确认本次输出的每张图片，再生成 PDF。

文件与退出
· 处理记录默认保存在 %LOCALAPPDATA%\VoucherWorkbench。升级时解压新包，保留这个目录即可继续使用原记录。
· PDF 输出到原分项同级的“分项-PDF”目录；原件不改动，不添加页眉页脚。
· 关闭网页不会退出服务。结束使用时在服务窗口按 Ctrl+C，等待当前任务停止后关闭窗口。
· 不要同时打开两份服务。重复启动会提示已有实例；请使用原有服务窗口中的链接。
· 解压目录和资料路径可以包含中文及空格；不需要把资料放进程序目录。

运行依赖
应用不需要安装 Rust、Python、Office、Node.js 或 Docker。包中已附标题 OCR 模型和 Windows ONNX Runtime CPU 库，应用运行时不下载模型。
OCR 原生库还依赖 Microsoft Visual C++ 2019 或兼容更新版的 x64 运行库。若界面提示模型或 DLL 不可用，先按原向生成仍可使用；需要识别时，从微软官方下载并安装 x64 运行库后重新启动：
https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist
运行库安装可能需要管理员权限，本工具不会自动安装系统组件。

识别局限
历史 3,270 张图片的 4 并行评估约需 23 分钟，工作台串行执行可能更久，实际耗时随设备和资料变化。
历史 39/3,270（1.19%）是模型未决率，不是准确率。识别可能误转、漏转或遇到混排；所有待输出图片均需人工核对并确认。
